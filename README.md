Projeto do site institucional da BC Energia. Projeto utilizado por todos.
Esse projeto foi desenvolvido baseado no [Next.js](https://nextjs.org/) inicializado com [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

## Começando

Primeiro, execute o servidor de desenvolvimento:

```bash
npm run dev
# ou
yarn dev
# ou
pnpm dev
# ou
bun dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver o resultado.

### Dependências

- `react`: Utilizado para construir a interface do usuário.
- `react-dom`: Fornecer APIs específicas do DOM para o React.
- `next`: Framework para construir aplicações React.

### Dependências de desenvolvimento

- `@commitlint/cli`: Biblioteca usada para garantir que as mensagens de commit aderem a uma convenção.
- `@commitlint/config-conventional`: As configurações de convenção para o `commitlint`.
- `@typescript-eslint/eslint-plugin` e `@typescript-eslint/parser`: Ferramentas que permitem ao ESLint lintar código TypeScript.
- `autoprefixer`: Um plugin PostCSS para adicionar prefixos automaticamente em CSS.
- `clsx`: Uma biblioteca JavaScript para condicionalmente concatenar classes CSS.
- `commitizen`: Uma ferramenta para formatar mensagens de commit conforme a convenção.
- `cz-conventional-changelog`: Ferramenta de linha de comando para formatar mensagens de commit conforme a convenção.
- `eslint`: Ferramenta de análise de código estática para identificar padrões no código ECMAScript/JavaScript.
- `eslint-config-next`: Configurações do ESLint para projetos Next.js.
- `eslint-config-prettier`: Desativa todas as regras ESLint que podem entrar em conflito com Prettier.
- `eslint-plugin-import-helpers`: Plugin ESLint para ajudar com importações de módulos.
- `eslint-plugin-jsx-a11y`: Verifica as regras de acessibilidade em elementos JSX.
- `eslint-plugin-prettier`: Roda Prettier como uma regra ESLint.
- `eslint-plugin-react`: Especifica regras ESLint para projetos React.
- `eslint-plugin-react-hooks`: Regras ESLint específicas para Hooks do React.
- `git-cz`: Uma interface de linha de comando que encoraja commit semântico.
- `husky`: Ferramenta para garantir que os commits sigam as regras estabelecidas.
- `inquirer`: Uma ferramenta de interface de linha de comando.
- `jest-environment-jsdom`: Adaptação do ambiente JSDOM para o Jest.
- `jest-watch-typeahead`: Ferramenta para realizar buscas por nome de arquivo ou nomes de testes enquanto se usa o modo watch do Jest.
- `lint-staged`: Ferramenta para rodar linters em arquivos staged do Git.
- `postcss`: Um processador CSS para transformar CSS com JavaScript.
- `prettier`: Ferramenta para formatação de código.
- `rimraf`: Alternativa para o comando `rm -rf` para Node.
- `tailwind-variants`: Uma biblioteca para adicionar variantes customizadas no Tailwind CSS.
- `tailwindcss`: Um framework CSS utility-first para desenvolvimento rápido de designs personalizados.
- `typescript`: Adiciona tipagem estática e outras funcionalidades ao JavaScript.
- `@types/node`: Tipos TypeScript para o Node.js.
- `@types/react`: Tipos TypeScript para a biblioteca React.
- `@types/react-dom`: Tipos TypeScript para a biblioteca ReactDOM.
- `prettier-plugin-tailwindcss`: Plugin Prettier que suporta a formatação de arquivos de configuração do Tailwind CSS.
